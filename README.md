# LNG与天然气热点

聚合 LNG 与天然气行业信息，关注价格、国内液厂与气井、运输、供需，以及影响天然气贸易的国际局势。网站按事件整理报道，生成中文摘要与日报，并提供 RSS、公开 API 和 MCP。

本仓库已完成行业配置；当前开发配置关闭自动采集和模型调用。信源核验成功不等于已持续采集、获得付费数据授权或已上线。

## 内容范围

| 分类 | 关注内容 |
|---|---|
| 价格行情 | 出厂价、到岸价、送到价、JKM、TTF、Henry Hub、竞拍与成交，保留日期和报价口径 |
| 国内气源与液厂 | 中国大陆液厂、井口、气田、页岩气、煤层气的审批、建设、试产、投产与检修 |
| 国际局势 | 对天然气供应、航道、结算或贸易有明确联系的冲突、制裁、关税和政策 |
| 运输与接收站 | LNG 船、槽车、运费、航道、接收站、储运与装卸能力 |
| 供需与库存 | 产量、进口、库存、需求、天气及其对供需的影响 |
| 政策 | 天然气监管、价格机制、市场准入、管网开放、保供储备及地方实施细则 |
| 贸易交易 | 长协、招采、成交、合同、并购与交易平台业务公告 |

有地点、时间和进度的小项目也应保留。招商广告、无出处报价、重复转载和无天然气关联的国际新闻会被压低。审批不能写成投产，设计产能不能写成实际供应，风险不能写成已经发生的涨跌。

政策有独立的 `/policy` 页面，支持政策内搜索、一手发布筛选和政策精选 RSS；桌面导航与移动端“更多”均有入口。

支持[普通用户账号](docs/member-accounts.md)：管理员在后台“用户管理”创建账号，用户通过账号密码登录后回到首页，可在“我的账号”修改密码或退出。整个站点及资讯接口均需登录；`/admin` 保持独立的管理员登录。

## 本地运行

需要 Node.js 24.11 以上和 PostgreSQL。完整的本机、Docker、域名及 HTTPS 说明见 [部署](docs/deploy.md)。

```bash
npm ci
cp .env.example .env
# 在 .env 填写数据库、管理员配置及必需的本地密钥
node --env-file=.env scripts/migrate.ts
node --env-file=.env scripts/seed.ts
npm run build -w @aihot/web
```

分别启动 API 和 Web（开发模式见部署文档）。开发期间保留 `COLLECT_ENABLED=false`、`MODEL_CALLS_ENABLED=false`、两个 `FEISHU_*_ENABLED=false`、`INDEXNOW_SUBMIT_ENABLED=false`。模型调用只发生在 worker 任务中，阅读页面不触发模型。

`seed.ts` 会更新主题，但只新增不存在的信源，不会覆盖后台配置或删除旧行业信源。已有数据库需要在后台核对并停用旧信源；不要把生产数据库用作测试库。

## 精选标准

LNG 评分提示词保留原来的内容类型、五维加权、噪声抑制和安全边界。入选门槛暂保留原值，**尚未用 LNG 样本校准**。请标注 100–200 条真实资料，再按 [精选与校准](docs/selection.md) 评估。`industry/gold.example.jsonl` 只是虚构的格式示例。

使用规则与隐私说明是[待确认草案](industry/pages/)，上线前由运营者填写主体、联系方式、数据用途和实际日志保存期限。
